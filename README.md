# 🚨 Fraud Detection Banking System

##  Overview
A full-stack system that detects suspicious banking transactions in real time using rule-based logic and machine learning.

---

## Features
- Real-time transaction monitoring  
- Fraud detection using MySQL triggers  
- Fraud alerts dashboard  
- Detection based on:
  - High-value transactions  
  - Multiple transactions in a short time  
  - Unusual location activity  
- ML-based fraud prediction  

---

##  Tech Stack
- **Backend:** Node.js, Express.js  
- **Database:** MySQL  
- **Frontend:** HTML, CSS, JavaScript  
- **Machine Learning:** Python, Pandas, Scikit-learn  

---

##  How It Works
1. Transaction is stored in database  
2. MySQL trigger checks fraud conditions  
3. Suspicious transaction generates alert  
4. Backend API fetches alerts  
5. Frontend displays alerts  

---




## 🔥 API Endpoints
- POST /transactions  
- GET /transactions  
- GET /alerts
